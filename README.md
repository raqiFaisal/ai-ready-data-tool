# AI Ready Data Tool

## وصف المشروع

مشروع تدريبي يهدف إلى بناء أداة بسيطة لتجهيز وتنظيف البيانات
قبل استخدامها في مشاريع الذكاء الاصطناعي وتعلم الآلة.

يركز المشروع على تطبيق أساسيات التعامل مع البيانات، وتنظيم ملفات
المشروع، واستخدام Git وGitHub لإدارة الإصدارات والتعديلات بطريقة منظمة.

## أهداف المشروع

- تعلم أساسيات تنظيف البيانات وتجهيزها.
- التعامل مع القيم المفقودة في البيانات.
- تنظيم ملفات مشروع الذكاء الاصطناعي.
- تطبيق Git في إدارة المشروع وتتبع التعديلات.
- استخدام GitHub لحفظ المشروع والعمل عليه من أكثر من مكان.
- التدرب على إنشاء الفروع ودمج التعديلات وإدارة تاريخ المشروع.

## المتطلبات

قبل تشغيل المشروع، يجب توفر البرامج التالية:

- Python 3
- Git
- GitHub Account
